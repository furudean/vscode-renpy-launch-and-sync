# Security policy

## Supported versions

Only the latest release of Ren'Py Launch and Sync is supported.

| Version | Supported |
| ------- | --------- |
| 5.x     | Yes       |
| < 5.0   | No        |

## Reporting a vulnerability

If you believe you have found a security vulnerability, please DO NOT disclose
it publicly until I've had a chance to fix it.

Please don’t report security vulnerabilities via GitHub issues, instead report them privately via the [Security Advisories](https://github.com/furudean/renpy-launch-and-sync/security/advisories/new) page.
